# Temporary NovaSharp brand mark

`nova-mark.png` is a temporary generated mark for the phase 4.5 workbench shell. It combines a four-point nova with
an `N`-shaped diagonal cut and is intentionally replaceable when permanent identity assets are selected.

The built-in image-generation tool produced the source on 2026-08-23 from this brief: a compact, vector-friendly nova
symbol with an `N` suggested by negative space, violet and soft-magenta flat colour, transparent background, no text,
and a silhouette that remains legible at toolbar size. The retained 256 px PNG is a downscaled project asset.
