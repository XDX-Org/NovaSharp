# Language-server third-party notices

NovaSharp distributions include pinned builds of the following projects:

- .NET Roslyn and Razor tooling, copyright .NET Foundation and contributors, MIT.
- Visual Studio Code HTML and CSS language services, copyright Microsoft Corporation, MIT.
- Visual Studio Code Language Server libraries, copyright Microsoft Corporation, MIT.
- TypeScript and TypeScript Language Server, copyright their respective contributors, Apache-2.0.
- Node.js, copyright Node.js contributors, MIT and bundled third-party licenses.

The acquisition process copies the complete C# extension, Roslyn/Razor dependency, and Node notices into each RID-specific package.
npm dependency license metadata remains in `node_modules`.
