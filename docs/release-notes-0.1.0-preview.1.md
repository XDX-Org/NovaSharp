# NovaSharp 0.1.0-preview.1

Unreleased.

This development preview contains the cross-platform editor workbench, SDK-style solution model, C#/Razor/HTML/CSS language servers, workspace search and replace, build/run output, and integrated terminal. It also introduces bounded foundations for managed debugging, durable recovery, permissioned extension manifests, and project-aware build configuration.

The build is not release-qualified until every Phase 18 gate in `phase-18-preview-release.md` has retained evidence. See `known-limitations.md` before testing.
